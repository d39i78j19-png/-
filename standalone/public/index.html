起動方法

キーはシェルの環境変数で渡します。ソースコードには一切書きません。

# 1) 顔写真の生成（機能3）
export GEMINI_API_KEY="AIza..."     # Nano Banana / https://aistudio.google.com/apikey

# 2) ペルソナ本文とAI診断（機能1・2）— 未設定ならルールベースで動作
export ANTHROPIC_API_KEY="sk-ant-..."

# 3) 起動
node standalone/server.js           # = npm run portraits:serve
# → http://localhost:8787

# 課金前にプロンプトを確認する（APIを叩きません）
npm run portraits:dry-run

キーを設定せずに起動した場合も、アプリは起動します。顔写真は事前生成プール （standalone/public/personas/pool/）があればそれを、無ければ プレースホルダを表示し、ペルソナ本文はルールベース生成に切り替わります。
一度生成した写真はプロンプトのハッシュでキャッシュされるため、同じペルソナを 何度表示しても課金は初回の1回だけです。

顔写真を事前に焼いておく

APIキーが無い環境でも顔写真つきで見せたい場合、先に生成してコミットしておきます。

# まずプロンプトと概算費用を確認（APIを叩きません）
node standalone/bin/generate-pool.mjs --dry-run

# 1枚だけ試して作風を見る
node standalone/bin/generate-pool.mjs --only male-01

# 問題なければ12枚まとめて
node standalone/bin/generate-pool.mjs --count 12

出力先は standalone/public/personas/pool/。サーバーは性別が合うものを 順に割り当てます。--wardrobe casual で私服、--scene office で オフィス背景になります。

生成した顔写真の扱い
・生成画像はペルソナ・デモ用です。実在の内定者・社員・顧客であるかのように提示しないでください。
・社外に出す場合は「※画像はイメージです。実在の人物ではありません」の注記を入れてください。
・Gemini の生成画像には SynthID の不可視ウォーターマークが入ります（無効化不可・画質への影響なし）。
